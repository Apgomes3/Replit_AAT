In the Life Support Area, add a new tab called Control.

This tab must include the following sections:

1. Control Panel Type

Allow the user to select the control panel type:

• GPO
• PLC

2. Field Instrument Selection

Allow the user to select the instruments required for each Life Support System.

A new Field Instrument Management area must also be created in Platform Admin. For each instrument type, the administrator must be able to define:

• Instrument name
• Tag code and numbering logic
• Description
• Signal type: analog or digital
• Signal direction: input or output
• Default linked PIM product
• Whether the instrument is mandatory or optional

Each selected instrument must receive a unique tag based on the LSS system number and sequential instrument number.

For example, a flow switch connected to LSS 01 would use the following tags:

01-FS-01
01-FS-02

The first number identifies the LSS system. The final number identifies the individual instrument.

The platform must automatically assign the default AAT PIM product associated with each instrument. The user may then review or change the selected product if permitted.
