Keep the Design Book Thermal interface on a scoped parchment, marine-navy, slate-blue, and copper palette. Do not introduce green or teal accents, and do not change the global application theme to achieve this.

**Why:** The user explicitly approved this non-green direction for Thermal while keeping the rest of the application visually unchanged.

**How to apply:** Use the scoped palette for Thermal surfaces, status accents, focused calculations, and Thermal governance controls. Preserve established global components and themes outside the Thermal workflow.
