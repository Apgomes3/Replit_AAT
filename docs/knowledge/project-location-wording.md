---
name: Project location wording
description: Product wording for politically sensitive project locations.
---

Project Management presents the project location field as “Country or Region” rather than “Country”. The stored field remains compatible with existing project records.

**Why:** This wording accommodates politically sensitive locations and avoids implying a single political classification.

**How to apply:** Use “Country or Region” in project-management labels, tables, exports, and selector context; keep the existing API/storage field compatible unless a migration is explicitly requested.
