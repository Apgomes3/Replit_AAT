---
name: UV revision continuation
description: How released UV evidence and new-revision navigation should interact.
---

Released UV selections are historical evidence and must never be refreshed from the live Product Master catalog. Continuing UV work happens in a new Draft revision, with navigation returning to the same LSS system and UV tab; that Draft presents the currently approved catalog choices for an explicit new selection and calculation.

**Why:** Designers need continuity without allowing current engineering values to rewrite the evidence that was actually released.

**How to apply:** Any released-to-Draft workflow launched from an LSS equipment tab should preserve the system and tab destination while keeping frozen selections out of the new editable calculation state.
